# React Unit Converter

I wanted to learn React. I think I found this idea on roadmap.sh. It took a few days to do this, but I learned a lot.

I used react-router-dom.

I ran into a few problems. I don't know why, but when I navigated to a converter page using a component, the props would update and the state wouldn't which caused a error. I couldn't find a solution. I ended up working around it. I realized realized from this that state management is complicated.

The second problem was related to front-end design. I have always struggled with design. I scrapped the initial layout and colorscheme in favor of something simpler. It looks better, but I'm still not super happy with it.

The third problem was trying to render this file as html. I realized I'm not familiar with async functions, Web APIs, and JS generally.
